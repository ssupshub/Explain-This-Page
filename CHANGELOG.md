# 📋 Changelog

## v5.3.0 - The "Modern Era" Refactor 🚀

_Release Date: December 2025_

### 🛠️ Technical Transformation

- **Full React/TypeScript Migration**: Rewrote the entire extension using React 18 and TypeScript for industry-standard stability and performance.
- **Vite Build System**: Implemented Vite for modern bundling, faster development, and optimized assets.
- **Robust Messaging**: Added auto-injection logic to handle "receiving end does not exist" errors automatically.
- **Stable Viewer Page**: Migrated from temporary Blob URLs to a permanent `viewer.html` extension page.

### ✨ Visual & UI Enhancements

- **Refined Glassmorphism**: Polished the design system with consistent Tailwind-based components.
- **Animated Stats**: Dynamic cards for pages simplified and words processed.
- **Interactive Jargon**: Hover tooltips for technical terms with a new design.

---

## v5.2.0 - The "Beautiful" Update 🎨

_Release Date: December 2025_

### ✨ New Features

- **Dark Mode**: Complete dark theme support that syncs with system settings.
- **Glassmorphism UI**: A stunning new interface with frosted glass effects, gradients, and subtle shadows.
- **PDF Export**: Download your simplified pages as clean PDF documents.
- **Copy to Clipboard**: One-click button to copy the simplified text.
- **Theme Toggle**: Manually switch between light and dark modes in the new tab.

### 🛠️ Improvements

- **Reading Time**: Added estimated reading time to statistics.
- **Enhanced Dictionary**: Improved word replacement algorithm with more contextual awareness.
- **Stats Persistence**: Better tracking of words simplified and pages processed.
- **Visual Feedback**: Pulse animations processing indicators.

## v5.1.0 - AI Logic Upgrade 🤖

_Release Date: November 2025_

### 🚀 Core Changes

- **Enhanced Logic**: Replaced basic dictionary matching with smarter context-aware "AI" logic.
- **Jargon Detection**: Doubled the dictionary of technical terms.
- **Performance**: Optimized text extraction to handle larger pages (up to 50k chars).

---

## v5.0.0 - The "New Tab" Revolution 💥

_Release Date: October 2025_

### 🔄 Major Architecture Change

- **Moved to New Tab**: Abandoned the overlay/modal approach entirely.
- **Why?**: Overlays were blocked by pop-up blockers and CSP. New tabs are reliable and offer unlimited space.
- **Full Page Support**: Now processes the _entire_ page, not just a summary.

### ✨ initial v5 Features

- Text Selection Mode implemented.
- Clean, distraction-free reading interface.
- "View Original" side-by-side toggle.
